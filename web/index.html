Unone 驗證遊戲

每一個都由同一份 Rust/Luau 引擎驅動：引擎決定模擬結果並發布語意狀態， 瀏覽器只負責把它畫出來。從 D:/Projects 執行 python -m http.server 8001 後開啟本頁。

老虎機 — Spine / Effekseer 表現層

三軸骨骼由引擎的 animation 狀態驅動（轉動 run → 停下 idle）， 中獎時依 world.effects 播放 Effekseer 光環。按 Spin 拉一把，Auto 連續play。

需要 WebGL2。不需要 WebGPU。

小瑪莉 — 泛用 Web runner

24 燈環、6 種圖案、跑馬燈加速再減速後開獎。整個畫面是引擎驗證過的 UI tree， 點圖案押分、Start 開始。這款遊戲由一個只拿到企劃與引擎封裝的子代理盲做。

UI 不需要 GPU；世界層若沒有 WebGPU 會回報 renderer 不可用並繼續執行。

憤怒鳥 2D — 泛用 Web runner

2D 物理、pointer 拖曳發射，以及由已驗證 content bundle 解析出的真實 SVG 資產。

世界層需要 WebGPU。
沒有 WebGPU 的瀏覽器仍可執行語意層：runner 會回報 renderer.available=false 並繼續推進模擬、UI 與存檔， 只是不畫世界。老虎機的表現層走 WebGL2，不受影響。
