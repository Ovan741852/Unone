# Red Alert-style RTS validation slice

日期：2026-09-05

這一輪先用既有 2D engine contract 建立 RTS business slice：Luau 負責單位資料、pointer selection、move command、attack、礦石資源、基地建造、ViewModel、UI 組合與 save schema；engine 沒有新增 `Unit`、`Selection`、`Command`、`Economy` 或 `RTS` 專用 API。

`check --types` 與 3 個 deterministic tests 通過：70 frame pointer selection/move、3 frame attack/build、1 frame versioned save restore。這證明目前 engine contract 足以承載第一個 RTS 可測試閉環；多單位群組、完整地圖/科技/戰鬥與跨平台 host 仍是遊戲端後續工作，不把這個 slice 標成 final gate 通過。
