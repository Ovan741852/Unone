These diagnostics locate CPU reference execution and manager input/result validation costs. Pair counts are algorithmic upper bounds, not instrumented candidate visits. input_body_bytes is equivalent USB1 payload size, not all allocation or copy traffic. GPU upload/readback is measured as zero for this CPU path because no GPU transport occurs. gpu_kernel is absent and has an explicit CPU-unavailable reason; absent GPU preparation/packing/upload/encode/readback/decode phases are not numeric zero measurements. Host monotonic timings exclude Luau argument/result conversion, bridge JSON marshaling, caller application work and backend/device/pipeline setup. Host encode/submit or readback wait, if available on another backend, would not be GPU kernel time; nested or overlapping GPU phases must not be summed as independent GPU times.
