- Native SVG gradient/alpha pixel checks passed at 80×40 and 320×160. Invalid XML,
  animation/script, external references, stylesheet elements and nested images
  are explicitly rejected. The surface's existing tree/size cache avoids uploads
  for unchanged frames; this does not add a per-asset parsed-tree cache.
- A real Windows release player exported from a relocated binary-only SDK rendered
  the SVG fixture for three frames. Its `native-render.png` was visually inspected:
  rounded teal/purple gradient with the white triangular icon, no PNG conversion.
- Found/fixed native export's stale PNG-only asset gate. New SVG export requires
  the **selected runtime** to declare `ui.images: svg-static`; old runtimes fail
  before activating output. 3D mesh texture loading remains explicitly PNG-only.
- Found/fixed native export omitting `content/presentation.json`. Web/native now
  share presentation/font packaging, with an additional default/font regression test.
- `sdk inspect` now includes resolved source paths, hashes and runtime descriptors,
  replacing the stale hardcoded Windows presentation list. It distinguishes
  hash-verified declarations from execution evidence and separately installed plugins.

   export with inline attributes/paths or use a PNG companion for those features.
