**事件與功能帳本**

`event_stream` 只有 IMG-CAV-01 的單幀觀察，無法建立時間先後。可見派兵選項、射擊模式、目標篩選、暫停、金幣和結晶；`feature_ledger` 均記為 exposure。AUTO 與騎兵具有選中樣式；不據此推論首次使用時間、首次解鎖時間或使用者有沒有困惑。

**最小驗證**

- 同種子、同鏡位截取安靜戰場、普通獲獎、較高獎級、密集怪潮；修改前後並排。普通獎應能保留目標輪廓與倍率，較高獎級應能被清楚區分。
- 在桌面與手機橫向各檢查一次；請首次觀看者指出目前兵種、選中目標、金幣與結晶。記錄錯認項目，不以零 UI 診斷錯誤代替視覺驗收。
- 若普通獎已清楚，而遮擋只出現在高獎級特寫，重新評估第三項優先度；若造型能被穩定辨識，停止追加常駐標籤。

**Skill 的實際幫助**

它讓此次判斷具備定位證據、樣本限制、修改順序與驗證方式；能把「畫面不好看」拆成可執行的工作。它提供的是分析方法，不會自行畫貼圖、設計圖示、改光照或讓遊戲變漂亮。本次僅完成檢視；美术與呈現修改仍待實作。
