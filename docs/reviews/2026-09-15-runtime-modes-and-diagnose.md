## Outcome

- Added `execution_mode()` metadata to platform capabilities, developer sessions
  and preview profile responses. Keeps diagnostic interpreter mode distinct from
  native-codegen eligibility and from host-managed Wasm JIT. No metadata enters
  canonical observations or Lua gameplay globals.
- Added read-only session `diagnose` with bounded failure/input/partial-change
  evidence, original diagnostics, attempted/completed frame, recording position,
  recent journal, concrete next request objects and explicit debugger limits.
  Exact entry-chunk source lines are promoted when actually reported; otherwise
  line/column remain unknown. This is not arbitrary stack-local inspection.
- Added one engine example and `scripts/verify-runtime-modes.mjs` for a diagnostic
  / unsampled production-mode pair over the same host payload and input stream.
  Build/input/source hashes, alternating process order, every-tick checkpoints,
  real Lua samples, raw timings and concrete failure evidence are retained.
- HTML overlay is the preferred human presentation route for browser/WebView
  hosts. Pure native wgpu still needs an explicit WebView host for HTML; existing
  native UI support was preserved. No new HTML/native host was implemented here.

## Limits and interpretation

The final production cost is a headless native CPU measurement. Canonical state
digests exclude packed instance poses under the existing engine contract. Pixel
identity, GPU/render time, general game acceptance, mobile devices, browser JIT
tiers and pure-native HTML support are not verified by it. Successful pairing
is not an optimization verdict. Evaluate old/new **production** workloads with
the same acceptance cases; diagnosis-mode timings must not substitute for that.

No upstream supported Luau-to-Wasm JIT backend was found. V8's Wasm JIT and
dynamic WebAssembly module compilation are real capabilities, but do not make
Luau's x64/arm64 code generator a Wasm backend. References and exact distinctions
are recorded in [runtime mode validation](../runtime-mode-validation.md).

`diagnose` remains connection-local and headless: no live-preview takeover,
source-level pause/resume, automatic fixes, private reasoning access or complete
Luau local-variable inspection. It reads after a tick failure, never rolls back
partially executed game state. Export/replay is an explicit separate action.
