# Lookahead inspector extension

Mode: Operate; retain the incumbent paper/jade person panel. The user wants residents to think about their next action while still executing the current one.

THESIS: Separate current execution from a future plan and its start timing, without inventing model reasoning.
OWN-WORLD: Existing typography, colors, spacing, native disclosure; no new assets or motion.
STORY: Select a resident; read current action/progress, next plan or pending state, then reveal source-matched probability evidence.
FIRST VIEWPORT: Add two short text rows to the existing mood/intent region; retain independently scrollable desktop/mobile details.
FORM: Luau-owned single queued plan, model-selected timing. No intent chosen in JavaScript; no fixed emergency override.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Scope: narrow extension, no system migration. Earlier in-thread images and archived-capture limitation documented in resident-identity-review.md. Same-agent visual inspection is not an independent formal review.
