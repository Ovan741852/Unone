# 全居民指示線與實際行動時間

2026-09-20；主代理規劃、審查與獨立驗收，Luna 實作。

## 範圍與所有權

- 所有存活且有剩餘路線的居民顯示指示線，不依賴人物選取、詳情開關或建築選取。線頭隨人物實際插值位置移動；路徑以 Luau 的格子資料為準，不憑空生成目的地。抵達、死亡或路線移除後清理線段。
- 瀏覽器只繪圖與顯示進度；Luau 管時間、移動、資源、配對與結算。這不是需要放進 Rust 引擎的業務規則。
- NanoJev 繼續獨立決定人物意圖、對象與 after_current／interrupt_now。120 幀錯開提交不代表必須換動作，也不代表推論能在 120 幀完成。

## 時間合約

- 一個行動開始時固定本次時長，依個人狀態、特質及有限變化取值；不能每幀重抽。走路與執行分開，未抵達、正在跨格或被共同互動佔用時不累計原行動的執行時間。
- 睡眠／休息、吃飯、攜帶食物、用藥、用品、購物及等待都有正的持續時間。夜間睡眠比日間短休長；吃飯與睡眠不是全員同一長度。這是模擬規則，不宣稱醫學或生活時間的精準模型。
- 消耗品／購物／用餐在實際完成時單次結算；中途改意圖不能領取未完成的完整效果。休息的逐步恢復及已完成的工作量保留。
- 工作、訓練、採集及狩獵沿用八個有效努力單位，體況較差完成較慢；以遊戲時間推進，不因渲染幀數多就額外生產。每班薪資、產量及中斷後已累積工作量維持帳務合約。
- 移動時間取決於實際行走；巡行到站保留正的停留時間。已完成單位不暗中開啟下一個巡點或重複生產。
- 治療等共同活動兩端共用一段按行為類型決定的實際執行時間；決鬥仍由實際接近、出招與結果結束。接受／拒絕的邏輯回覆、安全取消與死亡清理不刻意延遲。模型回覆的 90 秒窗口不隨模擬倍速縮短，避免因推論排隊代選結果；身體執行時間隨遊戲倍速、暫停。
- 完成一段休息不強迫人物改意圖或自動出門；未有 NanoJev 新指令且仍躺在家時可繼續恢復，進度必須明示本段已完成，不能裝成永不完成。
- 詳情显示實際已用／預定或估計時長，未知與舊版資料使用既有文案。模型收到同源進度，維持 1024 token 上限且不截斷。

## 驗收與部署邊界

- 40 人合成路線覆蓋、未選取／關閉詳情、切換選取、線頭更新、資源重用、抵達／死亡清理；保留姓名固定錨點與鏡頭功能。
- 生產 Luau 測試：正時長、個體／不同次變化、途中不累計、未完成不消耗、完成單次結算、暫停／倍速、提前規劃與中斷、工作與配對及金錢／庫存守恆。
- 所有合成測試只證明規則執行，不當作 NanoJev 行為品質或 live 更新證據。
- 檢查開始時 live 第 73 日、frame 782984，40 筆居民、1 人在世；新時間欄位尚未載入。保留此世界、不重啟 native/model、不重開 OBS／推流。
- 繪線可只重新載入遊戲頁與 OBS 的既有網頁來源生效；新的 Luau 規則需要重新載入 runtime。尚無本輪重開同意，不擅自清除直播世界。

## 結果

- Viewer 已部署：只 reload 原遊戲頁，並透過新 `town-broadcast.mjs refresh-browser` 命令 refresh 既有 Town browser；不改場景／音訊／推流設定。主代理畫面驗證在人物詳情關閉、未選取存活居民的情況下，其路線仍可見。OBS 1920×1080 預覽亦看到相同路線與本輪任務列。
- 主代理獨立通過 `node tools/check-routes.mjs`（40 人覆蓋、選取獨立、移動、geometry/lineDistance 重用、抵達／死亡／移除清理）、`check-status`、`check-labels`、`check-camera`、`check-biography`、`check-buildings`、broadcast offline 8/8。
- impeccable clarify 用於進度的預計／預估／缺失資料區分；未重新設計原介面。detector 僅在 app.js 報既有動態 img 模板警告；初次載入時隱藏詳情頭像未設來源，不當作可見破圖或聲稱全頁稽核。遊戲頁無 console error。
- 第一輪 Luau gates：check --types、verify、test 通過；既有 non-strict 警告保留。舊 tape 回放至 7,200 幀採樣最小間距 2（一格），經濟回放至 21,600 幀 money_delta 全 0。並行回歸不是效能基準，也不代表新模型行為品質。
- 最終時長專項通過，360 筆生產請求最高 847/1024 tokens；完整雙人測試 166 筆最高 945/1024，均為本地 tokenizer，不載入模型權重、不截斷。人格 40 人、四鄰人壓力測試通過；15 類人格反應測試最高 873/1024。
- 主代理獨立通過 lookahead（150／300／3600 幀兩種切換時機）、realism、life（至 10,800 幀日夜／休息）、cemetery 與 paired 回歸。最後重新跑 duration／realism／paired 通過。
- 最終 `game verify` 四 gate 全過，含官方 Luau analyzer、assets、layout、4/4 deterministic cases。中間曾遇推論型別複雜度錯誤；僅為既有動態 applyDamage 邊界加入局部參數與 number 回傳型別，不停用 analyzer、不加 nocheck。
- 詳情互動實查有 40 個居民按鈕、可見破圖 0；關閉詳情回到自由觀察。OBS 最後仍 active，保持原六來源及原輸出尺寸，不重啟推流。
- **部署狀態：繪線／詳情相容已上線；新 Luau 時長與前輪雙人規則仍等待重開同意。未以舊世界影像宣稱新時間規則已生效。**
