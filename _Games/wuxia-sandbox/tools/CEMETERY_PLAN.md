點墓碑沿用居民詳情，顯示姓名、死因、生前資料與遺產。

- **辨識與互動：**已故居民顯示低多邊形石碑與基座、姓名及「已故」；可透過
  點選、鍵盤或居民名冊開啟既有詳情。保留生前頭像、價值觀、背景、關係和遺物。
  不顯示活人的血條、目的線、下一步計畫或跟隨操作；未記錄的死亡時間及兇手不補造。
- **墓園與所有權：**獨立墓園最多容納 40 個固定、不重疊的墓位，保留通路。
  Luau 決定死亡、位置、墓位占用和尋路阻擋；JS 只繪製 Luau 提供的位置與狀態。
  不添加規則式人物意圖，不修改 NanoJev 決策或把生死判定移到 JS。
- **資料保全：**僅 `alive == false` 是亡者。舊版存在 `injury == 100` 但仍存活的
  居民，本次不得因此殺死他們。保留現金與道具守恆；不要刪掉亡者人物資料。
- **相容與部署：**舊 native 沒有墓園欄位時，可原地呈現墓碑，不能在 JS 假搬家。
  新墓園需要載入新的 Luau。現有程序無完整遊戲存檔／還原適配，且未以 watch 啟動；
  不以不完整 observation 假稱完整還原。是否重新開局仍待使用者部署選擇，
  在此之前不得重啟 live native、模型 worker 或 OBS。
- **驗收：**測試 0/1/21/40 亡者、墓位唯一且不占建築/入口、活人不穿碑、重開清理、
  0 HP 存活負例，以及輸入 snapshot 不被展示層修改。獨立測試不能冒充真實模型事件。
  主代理完成瀏覽器點選與畫面驗收後，再套用直播來源；串流維持小鎮網頁、任務列、
  已授權音樂及署名，不新增擷取來源。
