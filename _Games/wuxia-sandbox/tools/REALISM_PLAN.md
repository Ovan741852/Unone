# 擬真第一輪：身體、後果與可追溯事件

2026-09-19。主代理規劃與驗收，Luna 實作。

## 已確認的問題

- 舊直播世界第 56 日保留 40 人，39 人的死因都是攻擊累積傷勢；不能把大量死亡歸因於飢餓。
- 最後一位在世居民傷勢已達 100，仍能執行動作。原始碼的狩獵傷害沒有統一進入死亡處理。
- 固定週期的見聞會宣稱蘇晚晴聽見新消息，甚至在她死亡後繼續顯示；這不是實際互動紀錄。
- 身體狀況對執行能力的影響不完整。模型看得見狀態，不等於會做合理的生活決策。

## 本輪範圍

1. Luau 用有界、可測試的體能係數，讓疲勞、飢餓、傷勢降低執行效率；休息的時間式恢復沿用現有規則。
2. 傷害與死亡共用一致入口，修正狩獵致命傷不死亡；死亡只結算一次，取消規劃／占格，保留遺產。
3. 命中／MISS／非致命切磋保持不同後果，死因只記錄實際來源，不猜測兇手或動機。
4. 移除沒有事實支撐的週期見聞；保留真正的決策、互動、交易與戰鬥事件。
5. 狀態面板與 NanoJev 輸入共用同一份體能資料，說明執行後果，不代替模型選擇。

係數是遊戲平衡參數，不是醫學或心理學模型。意圖、對象、切換時機仍完全交給 NanoJev。不能用擬真之名加入規則 AI、強制睡覺、強制反擊或人格硬性覆寫。本輪不加飢餓致死、流血、警察、產權、繼承或新的模型訓練。
