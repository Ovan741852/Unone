# Native Legion battle probe

100,000-unit default load, seven unit types, combat and effects in Luau.
Native Windows / Android renderer: instanced meshes, distance LOD, frustum culling,
normal/additive particle billboards. No per-unit rigid bodies or skeletal animation.

See [measured platform results](../../docs/native-battle.md) before choosing a load.
The pressure variants keep troops alive; they are generated by
`scripts/prepare-legion-native-stress.py`. The default game permits casualties.

Models and palette: [asset provenance and CC0 licenses](ASSETS.md).
LOD meshes are generated with `scripts/build-mesh-lods.py`; the farthest LOD is
intentionally coarse. Magic/arrow trails use fading particles, not ribbon geometry.

Build a native runtime with `scripts/build-native-player.ps1 -LuauCodegen`, pack it
with `game sdk pack`, then `game export platform --target windows` or
`--target android-x86_64`. Android packaging requires SDK/NDK/Java and a signing key;
the supplied packager creates a local testing key, not a store publishing identity.
