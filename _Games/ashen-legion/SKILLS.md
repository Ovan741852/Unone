# 部隊技能組合

技能與結算由 `main.luau` 的 Unone Luau 執行，UI 只讀取 `game.loadouts`。

## 現行規則

- 劍兵：每次傷害 10% 爆擊、1.5 倍。預設第一個接觸命中後消失。
- 槍兵：投射落地，旋轉 0.55 秒；範圍內每個目標最多一次 1.8 倍傷害。之後前進，接觸命中後消失。
- 騎兵：前四個接觸命中造成傷害並穿透，第五個接觸命中造成傷害後消失。
- 裝備「穿透 +1」逐份相加。劍兵 +1 是兩次接觸，騎兵 +1 是六次接觸。
- 旋轉技能可裝到任何兵種。旋轉不消耗穿透，與接觸命中分別去重；同一個存活怪物可以先受旋轉傷害，再受一次接觸傷害。
- 同一士兵的接觸傷害對同一怪物最多一次，避免重疊或反彈重複扣次數。
- 牆面反彈不消耗穿透。壽命到即消失，回合結束存活者按出發時價格退款。
- 爆擊按每次有效傷害獨立判定，包含旋轉斬；傷害破防後才進行一次開獎。溢出傷害不追加開獎。
- LOCK／AUTO 延續目前的單一目標限制，不會為了穿透而打到其他怪物；手動射擊可穿過不同怪物。
- 「死靈法師」：部隊真正接觸死亡或壽命到期時，38% 機率化成鬼魂，0.34 秒衝向 5.8 單位內最近目標；撞擊半徑 1.25，最多三怪，主目標受 34% 基傷、波及各受 16%。每名玩家最多同時六魂；召回不觸發。

## 霜牢碎裂表現

- 「凝霜符文／凝霜之握」仍只負責緩速；畫面會在受緩速怪物周圍形成低模六面冰晶牢籠，跟隨目標並依套用／消退階段升起或淡出。
- 「碎冰刃」命中已緩速目標時，既有碎冰波會表現為擴散冰環與 40 枚具確定性軌跡的多面冰片。玩法傷害、一次觸發限制和控制時間都維持原規則。
- 特效共用既有 Three.js 固定 GPU 批次；降低動態效果時減少碎片數及發光強度，不另外建立逐粒子網格。

## 招魂組合

- 死靈法師 + 油甕遺贈：亡兵留下油池，鬼魂爆裂算火焰，可引燃沾油怪與油地表。
- 死靈法師 + 雷紋接枝 + 喚雨擊：鬼魂傷害轉為閃電，打中潮濕怪會接既有的傳導規則。
- 死靈法師 + 引力法則：先把小怪聚近，再讓死亡鬼魂更容易撞到一群目標。
- 死靈法師 + 焰葬：鬼魂擊殺可引出一次屍體爆燃；焰葬自己的次級爆炸不會再觸發焰葬，避免自我連鎖。
- 死靈法師 + 薪火相傳／英魂託付：同一名士兵死亡時，既有的友軍增益和召魂都可發動，讓犧牲也能推進隊伍。

鬼魂不再視為部隊，不會召出另一隻鬼，也不會增加掠奪金幣、主要命中計數或爆擊；鬼魂傷害仍走一般破防、開獎與獎金流程。倍率與範圍沿用強化規則，且同一玩家的同時鬼魂數有上限。

## 擴充方式

`skillDefinitions` 定義效果，`innateSkills` 定義兵種天生來源，`S.skillSources[兵種]` 存放額外來源。
來源格式為 `{id="pierce", stacks=1}`。未提供 stacks 時為 1。
將來頭、身、腳、手、武器或符文可以各自提供來源，換裝時重建額外來源清單，避免把永久加值留在兵種上。

`composeSkills` 在出兵時建立獨立快照。穿透次數、爆擊率相加；爆擊率限制 0–100%，倍率取最大值。重複取得旋轉技能只解鎖一次，不重播多個旋轉；半徑強化另算。
`contactHit` 共用傷害與穿透／死亡處理。移動按路徑交點排序，避免怪物陣列順序決定穿透對象。

新技能若需要新的觸發時機，應新增明確效果處理，不以兵種類型判斷是否有技能。現有元素符文仍使用單槽規則，並非所有符文都自動堆疊。
