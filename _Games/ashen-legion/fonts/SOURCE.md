# Native UI font

`NotoSansCJKtc-Regular.otf` is Noto Sans CJK Traditional Chinese from the
official Noto CJK repository:

https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/TraditionalChinese

The font is distributed under the SIL Open Font License 1.1. The license text
is included in `LICENSE-OFL-1.1.txt`. It is bundled with the game so native
Android/Windows hosts do not depend on the device's installed CJK fonts.
