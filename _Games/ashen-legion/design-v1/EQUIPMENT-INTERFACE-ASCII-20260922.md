# 部隊裝備介面 v2

這頁固定分成兩層：先在配置層選部隊與部位，再在詳情層確認一件裝備。兩層使用同一套榛姨風格的森林綠、橡果金與暖米色，但資訊密度不同。

```text
配置層：先決定「誰」和「哪個部位」
┌──────────────────────────────────────────────────────────────┐
│ 部隊裝備                         金幣 320   結晶 0       [×] │
│ [裝備] [符文]                                                   │
│ [劍兵 4金]   [槍兵 10金]   [騎兵 20金]                         │
│ ┌──────────────────────┐   ┌──────────────────────────────┐ │
│ │ 劍兵 · 配置            │   │ 武器 · 可穿戴                 │ │
│ │    [頭]       [手]     │   │ ┌─────────┐ ┌─────────┐       │ │
│ │    [身]     角色紙娃娃 │   │ │圖│名稱   │ │圖│名稱   │       │ │
│ │    [腳]       [武器]   │   │ │  效果   │ │  效果   │       │ │
│ │ 部隊屬性  傷害 壽命…   │   │ │[查看]   │ │[查看]   │       │ │
│ └──────────────────────┘   │ └─────────┘ └─────────┘       │ │
│                              │ ┌─────────┐ ┌─────────┐       │ │
│ [卸下]                       │ │         │ │         │       │ │
│                              │ └─────────┘ └─────────┘       │ │
│                              └──────────────────────────────┘ │
│                                           [整備完成 · 出戰]    │
└──────────────────────────────────────────────────────────────┘

詳情層：只回答「這件裝備值不值得穿」
┌──────────────────────────────────────────────┐
│                 裝備詳情                 [×] │
│   ┌────────────┐  雷枝戰槍                 │
│   │            │  武器 · 稀有               │
│   │   技能圖   │  爆擊雷鏈兩怪               │
│   │            │  派兵費 +6 金               │
│   └────────────┘                             │
│   ┌────────────────────────────────────────┐ │
│   │ 施放瞬間：閃電從持有者身上放出          │ │
│   │ 命中：連鎖、浮動傷害、雷光尾跡           │ │
│   │ 附魔：……                               │ │
│   └────────────────────────────────────────┘ │
│     [穿戴此裝備 / 轉交此裝備]   [返回清單]   │
└──────────────────────────────────────────────┘
```

配置層保留常用的拖曳視線：左邊是部隊身上的五個部位，右邊是裝備清單；詳情層才展示完整效果與 VFX 提示，避免清單卡片被長文擠壞。清單改成兩欄寬卡，讓名稱、效果、派兵費和查看動作各自有固定位置。
