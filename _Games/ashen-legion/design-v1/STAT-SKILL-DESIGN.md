# 數值皆可成為技能：設計框架 v4

依使用者方向：所有數值都可以用來發想技能；裝備與附魔越強，付費部隊的派遣成本越高，五槽不必填滿。此為候選設計框架，未代表全部技能已實作或同時加入掉落池。

## 四種設計方式

1. 直接改值：速度 +15%、壽命 +15%。容易理解，是配裝底座。
2. 條件觸發：剩餘壽命低於 25% 時，下一次主要命中增傷；不必每個技能都再抽一次機率。
3. 數值轉換：移速加成轉穿透傷害；低速度換重擊；犧牲壽命換爆發。
4. 累積與消耗：反彈蓄傷、穿透蓄終結、連殺維持狂熱。玩家看得到存量與消耗時機。

「全部都能發想」不等於把每個數值都做成獨立卡片，更不等於所有數值都無上限。先讓少量容易理解的核心互相搭配，再擴充。

## 數值 → 技能候選

| 數值來源 | 技能例子 | 必須說清楚的取捨 |
|---|---|---|
| 傷害 | 重刃：主要傷害 +35%，地面速度 -20% | 慢到沒碰怪就到期仍是虧本 |
| 速度 | 勢能：正向速度加成轉穿透傷害 | 只讀地面速度倍率，不拿投射飛行瞬速灌傷害 |
| 壽命上限 | 長征：壽命 +15% | 不增加可撞次數；普通劍兵仍第一撞消失 |
| 剩餘壽命 | 最後一搏：剩餘低於 25% 時，下一次主要接觸 +40%，每兵一次 | 不延命、不免死亡，沒撞到就沒有收益 |
| 經過時間 | 熱機：出發後每滿 1 秒，主要傷害 +5%，最多 +25% | 要活得久又打得到；不是閒置就賺錢 |
| 行走距離 | 遠征：實際地面路程滿 12 單位，下一次主要接觸 +30%，每兵一次 | 不計瞬移／召回／裝飾位移；轉角路程分段累積 |
| 反彈次數 | 越彈越猛：每反彈增傷；回春：反彈增加少量壽命 | 角落雙軸一次碰撞算一次；每兵獨立，公開上限 |
| 穿透餘額 | 勢如破竹：尚有穿透時享速度轉傷；破陣：用完穿透後終結重擊 | 前段與末段加成分開，不能每次都算終結 |
| 爆擊機率／倍率 | 鷹眼加機率；猛擊加倍率；決勝每第三次主要命中必爆 | 沒有爆擊機會時，單買倍率可能沒有收益 |
| 範圍半徑 | 寬刃：半徑 +20%，範圍技能傷害 -10% | 半徑 +20% 約為面積 +44%，不能按直徑線性估價；普通身體碰撞不自動變大 |
| 命中數 | 回響：同一次主要技能命中至少三個不同怪，獲一次小範圍副效果 | 同怪只算一次，副效果不能自我觸發 |
| 連殺數／間隔 | 狂熱：5／10／15 層升級，斷殺逐步掉層 | 依真實死亡與玩家歸屬，不把王的小獎算擊殺 |
| 目標目前破防進度 | 裂甲：怪物已累積超過 70% 破防值時，主要接觸 +20% | 按該次命中前的怪物狀態判斷，不修改破防門檻，不保證中大獎 |
| 目標距離／密度 | 孤獵：目標周圍無其他活怪時增傷；聚獵：附近多怪時擴張刀環 | 定義查詢半徑與目標數；數值由 Luau 觀測，不依畫面遮擋 |
| 派兵成本 | 精兵：增加能力也提高每支費用；節制：少裝一件，保留便宜備用兵 | 購入成本與反覆派兵成本必須一起評估 |
| 當前金幣 | 徵募：低資金觸發有限次派兵折扣 | 次數按玩家／回合記帳；反覆穿脫、餘額跨門檻不重置 |
| 累積派兵支出 | 集結：每輪達到支出門檻給一次短暫軍團增益 | 只計實際付費出兵；不能折扣前金額灌門檻；每輪次數有限 |
| 射擊間隔 | 急募：短時間提高派兵頻率 | 每兵照價付費，錢也耗得更快；不變免費連射 |
| 在場部隊數 | 孤軍：在場僅一支付費部隊時增傷 | 判斷屬於同玩家的付費活兵，免費援軍與死亡殘影不混計 |
| 回合剩餘時間 | 決戰：最後 30 秒，指定兵種主要傷害提高 | 顯示為限時光環；不延長大王出場窗口或偷偷改其他玩家時間 |

以上是可選設計，不是全部承諾加入第一版。每個技能卡最多一個主效果加一個代價，複雜組合由多件裝備形成。

## 派兵成本的正式設計口徑

局內購入／附魔費是一次性取得成本；每次派兵另算「基礎兵價＋已穿戴装備派遣加價＋附魔派遣加價」，再套有效派兵折扣／價格懲罰，向下取整且至少 2 金幣。不把裝備購入價直接逐次收取。

裝備和附魔卡分別顯示購買價格、每次派兵加價、穿戴後總價與目前可派支數。背包未穿戴不加價；卸下只影響未來出兵，已出發的成本與裝備快照不變。

實際派兵價在出發時存為 paid，退款最多就是這筆 paid；增益、被動援軍、殘影與副技能不生成可退款成本。科技與城鎮增益先不提高派兵價，保留局內與局外養成收益。新增命中／範圍能力的價格不必與單純 +10% 傷害相同，應用實際收益與組合價值定價。

例如劍兵 8 → 穿透裝 +4 = 12 → 爆擊裝 +3 = 15 → 群攻附魔 +6 = 21；全部是測試示例。比較應包含「一支 21 的組合兵」對「三支 8 的基本兵」的總投入，而非單兵傷害高就視為划算。

蓄獎怪累積值若來自支出，也只計符合目標條件的 paid 一次；不重複計穿透命中、雷鏈或附魔副效果。開獎倍率、基礎獎金與付費派兵產生的獎池輸入要一併驗守恆與收益，不能靠昂貴裝備灌投入就穩賺。

## 合成與即時增益

技能資料至少包含 id、來源物品／科技、觸發事件、條件、讀取數值、修改目標、運算方式、持續時間、疊加／消耗／上限、派兵加價、特效事件。可用資料描述已支援的操作，不允許任意字串公式隱式改遊戲規則。

計算順序：兵種基礎 → 出發時裝備／科技快照 → 玩家即時光環 → 每兵累積與當次條件 → 該次爆擊 → 破防與開獎 → 允許的一層副效果。每個公式明訂哪些來源參與，避免速度讀了傷害、傷害又改速度的循環。

派兵價與壽命上限預設出發快照；連殺、決戰屬明確即時光環。副效果不得讀上一次渲染的動畫位置或因播放完成回呼自行計傷。所有邏輯留在 Luau；引擎只提供已有的動畫／VFX／UI 能力。

## 第一版挑選與驗證

優先：壽命、速度、穿透、爆擊、反彈、終結、群攻與派兵成本，足以組出已定義六流派。第二批再加路程、剩餘壽命、密度、在場兵數等條件，避免初期二十多種新觸發造成閱讀負擔。

快測先比較同總金幣投入的裸裝／便宜專精／豪華混合，以及技能有效觸發次數、未命中死亡成本、打王效率、回收／獎金與最終通關。數值變多不等於變好玩；每件裝備要能用一句話說明為什麼現在想買。
