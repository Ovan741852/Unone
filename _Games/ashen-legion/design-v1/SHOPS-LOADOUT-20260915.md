# 隨機專賣店與部隊配置

2026-09-15。這次是遊戲流程和介面編排，由 Luau 負責，沒有新增引擎能力。

## 每輪流程

行軍 → 隨機三個不同景點 → 選一個拜訪 → 購買／出售 → 部隊配置 → 明確按出戰。

每輪從裝備店、符文店、藥水工坊、軍團研究、附魔鐵砧、荊棘契約抽三個，不再固定前兩輪出裝備店。各轮可抽到以前去過的地點，但同輪不重複。背包沒裝備時不抽附魔；第六、七輪不抽無法等到收益的兩輪詛咒。種子固定時選項可重現。

## 商店

裝備店只買賣裝備。符文店只買賣符文。其他地點保留自己的藥水、科技、附魔或契約。購買装備與符文只進入共用背包，商店不提供穿戴操作。

購物後先進部隊配置；返回同一商店會保留原本商品、售出狀態、刷新次數、研究與附魔次數。仍可使用原本付費刷新規則；切頁不是免費刷新。待確認附魔詞綴必須先採用或保留，才可離開。

## 部隊配置

主選單、景點選擇與購物後可進入。劍兵、槍兵、騎兵分别顯示五個部位：頭、身、腳、手、武器。點部位或部位圖示會篩選共用背包；顯示已穿戴物件、目前持有人、技能、附魔名稱和派兵費。裝備一次只能由一個兵種穿戴，轉交會從原兵種卸下。

符文有獨立配置頁：購買後進共用符文袋，裝入／卸下／轉交均不再付費；卸下回到袋中。每種最多三枚，分配不會複製數量。出售只能在符文店賣袋中的符文。裝備店也不能出售仍穿戴的裝備。

只有完成拜訪的整備畫面可按「整備完成・出戰」。從景點或主選單進入配置時，必須返回原流程，不能直接略過商店。配置與購物不扣戰鬥倒數。
