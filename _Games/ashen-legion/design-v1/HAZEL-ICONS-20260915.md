# 榛姨圖示風格

以 `assets/formal-ui/quartermaster-v1.png` 為風格基準：暖金邊光、橄欖綠布料、赤褐皮革、象牙白金屬亮面、切面陰影與輕微顏料紋理。

已更新 201 個圖示資產（含開發檢視器保留的瞄準準星）：77 個技能、77 件裝備、屬性／部位／藥水／操作符號，以及 6 種建築。正式遊戲仍只有 LOCK／AUTO 開關。

建築重新繪製外型：林間集市的棚布貨攤、藥水工坊的尖屋與藥瓶、鐵砧工坊的煙囪爐火、軍團塔、荊棘契約小屋、領主城堡。景點的詛咒選項改用契約建築，不再用詛咒道具圖代替地點。

装備去除額外的灰色圖示底板；劍、皮靴、手套、旗幟重畫了輪廓與材質。技能保持各自的動作符號。來源為可編輯的原創 SVG；沿用正式 UI 出圖流程烘焙為 PNG，沒有執行時材質濾鏡。

- `tools/icon_art.py`：圖形、配色、建築與語意。
- `tools/hazel_icon_style.py`：逐材質面上色、細邊光、切面和顏料紋理。
- `tools/build_equipment_art.py` → `tools/build-formal-ui.mjs` → `tools/finish_export.mjs`：現有製作／匯出流程。

同時移除「即將破防」文字：目標 HUD 和怪物浮動文字都不再出現；未鎖定小怪不會因接近破防自動冒出姓名條。選中目標的實際破防進度維持可讀；沒有改變破防或開獎規則。

驗證與畫面在 `tests/hazel-icons/`：201 個圖示風格標記完整，128／48 px 檢視、實際城鎮／景點／商店／裝備／戰鬥畫面，無 UI 資產診斷錯誤。另以 90% 破防進度的呈現輸入確認：未選中小怪沒有額外姓名條，選中時只顯示一般破防進度。
