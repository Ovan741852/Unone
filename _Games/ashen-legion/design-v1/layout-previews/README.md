## shop-v2

只做版面預覽，沒有改正式遊戲載入路徑，也沒有覆蓋任何素材。

- 目標：裝備店
- 變更：三欄商品大卡 → 左側選中商品詳情 + 右側商品網格
- 沿用：森林領主既有墨綠／舊金／磚紅 token 與透明-v2 精細手繪素材
- 保留：金幣、結晶、商品名稱、效果、價格、攜帶量、返回與前往配置動作
- 刻意不做：重新生成角色、把文字烙進圖片、改 Luau 經濟規則、替換正式圖片

## 審核結果

預覽需先檢查：桌面 1440×900、窄螢幕 900×600、手機寬度、商品圖片完整性、中文可讀性、
按鈕層級與資訊密度。使用者確認後，才把同樣的排版接回 `ui/formal-ui.luau`。

## shop-v3-hades-study

以 `design-v1/references/` 的 Hades 研究圖抽取設計原則後的預覽：暗色墨板、稀有度標籤、
卡片內圖框、強選中框、底部稀有度色條。沒有使用 Hades 圖片作為遊戲素材，沒有改正式遊戲。
1440×900 與 900×600 都能完整顯示，四張卡片圖片和四個稀有度標籤已通過瀏覽器 smoke check。

## shop-v4-merchant-horizontal

目前的商人包裝互動預覽：左側放商人與商店訊息，右側將四件商品水平一字排開。

- 每列顯示圖示、稀有度底板色、名稱、簡短故事、價格、士兵消耗變化量、持有量與查看詳情。
- 卡片上方只保留商品名稱；部位／屬性與技能背景整合進短說明，稀有度不另放標籤而直接用底板色表達。
- 商品卡由左至右錯開進場，商人面板同步從左側淡入；手機寬度維持單列並可左右滑動。
- 視窗採置中浮層，不滿版；後方遠征場景加暗化與模糊，並以標題列、陰影與邊框建立獨立遊戲視窗感。
- 點商品列或「查看詳情」會開完整彈窗，包含故事、發動條件、完整技能效果、適合流派與購買／裝備按鈕。
- 仍沿用森林領主的墨綠、舊金、磚紅與透明-v2 手繪素材；Hades 只作為資訊層級與選取框的設計參考，沒有把 Hades 圖片或裝飾放進遊戲。
- 這是獨立預覽，正式遊戲 UI、素材與載入路徑尚未修改。
