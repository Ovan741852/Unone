# 部隊骨架動畫規格

狀態：既有紙娃娃展示器有綁骨與八個示範動作；盤面部隊尚未接上這套骨架動畫。以下為正式戰鬥接入要求，不能把展示器播放當成遊戲已支援。

## 風格與共同原則

Q 版大頭短肢、低模繪本色。輪廓、武器姿勢與重心要誇張清楚，避免微小寫實細節在俯視盤面看不見。待機有呼吸與重心變化；跑步有明顯抬腳、擺臂，不是整個模型上下漂浮。

身體共用可接 Mixamo 的骨架，頭／身／腳／手為同骨架換裝；武器掛手部插槽。換裝不重建骨架、不重播出生、不重置動作。騎兵另有坐騎骨架，人物與坐騎時鐘同步，但坐騎不能被當作第二個付費士兵。

## 動作清單

| 動作 | 建議長度 | 何時用 | 表現 |
|---|---|---|---|
| idle 待機 | 1.8 秒循環 | 城鎮、整備、展示器 | 呼吸、握武器、重心輕移 |
| walk 移動 | 0.8 秒循環 | 展示器與慢速移動 | 短步幅、擺臂 |
| run 奔跑 | 0.55 秒循環 | 場內衝鋒 | 身體前傾，武器保持可讀姿勢 |
| stretch 伸懶腰 | 2.2 秒單次 | 城鎮與展示器闲置 | 舉手伸展、放鬆肩膀；不插入戰鬥 |
| spawn 出生 | 0.25 秒單次 | 炮台派兵 | 蓄力蹬地、武器抬起；不延後實際派兵時刻 |
| attack 攻擊 | 0.22 秒單次 | 普通接觸 | 劍兵短斬、槍兵前刺、騎兵壓槍 |
| pierce 穿透 | 0.12 秒單次 | 傷害後仍有穿透存活 | 前衝／短刺，腳部保留前進動勢 |
| rebound 反彈 | 0.10 秒單次 | 碰到場地邊緣 | 身體向反射方向側傾、腳部蹬地 |
| launch 投射 | 0.15 秒轉入 airborne | 有落地旋轉技能出發 | 收腿、武器往後帶 |
| airborne 飛行 | 循環／隨行程取樣 | 投射階段 | 空中抱勢，與 Luau 飛行位置同步 |
| land 落地 | 0.08 秒過渡 | 飛行結束 | 屈膝壓低重心，銜接旋轉前段 |
| spin 旋轉斬 | 0.55 秒單次 | 有旋轉技能落地 | 身體與武器完整轉一圈，收勢後立刻前進 |
| finisher 終結 | 0.18 秒單次 | 最後接觸後消失 | 一次幅度較大的收尾斬／壓槍，接碎葉散去 |
| death 死亡 | 0.35 秒單次 | 展示器、一般死亡演出 | 膝軟／失衡倒下；戰鬥可縮為清晰短散場 |
| expire 到期 | 0.20 秒單次 | 壽命耗盡 | 力量消退、武器垂下，身形散成葉片 |
| recall 召回 | 0.25 秒單次 | 回合結束或召回藥水 | 收武器、身形收束為金光並飛向玩家 |

land 過渡包含在 spin 的起始視覺段，不把遊戲的 0.55 秒旋轉額外延長。死亡／到期／召回邏輯立即結算，只保留無碰撞的短命視覺殘影收尾；殘影不產生傷害、不算存活、不退第二次金幣。

## 三兵種差異

- 劍兵：低重心小跑；命中短促劈斬；有穿透時邊斬邊向前越過，不停在原地連砍。
- 槍兵：投射時握槍收腿；落地槍刃畫出一圈大弧，之後換前刺衝鋒。旋轉來源可換給劍兵／騎兵，姿態按實際武器選 clip，技能不硬綁兵种。
- 騎兵：馬匹四足奔跑、人物隨馬身起伏；穿透逐次壓槍，終結時較重一下。反彈採短側傾與轉向，不倒著跑。旋轉技能若裝到騎兵，以人物持槍橫掃配合坐騎轉身，不把馬當直立人形硬轉骨架。

## 時序與動畫銜接

出發→奔跑，或出發→投射→飛行→旋轉→奔跑。奔跑中可觸發穿透／反彈；終結、到期與召回打斷低優先動作。終結接觸的揮擊與消失是一條演出，不再完整串播一次 attack 加一次 death。

移動循環之間漸變 0.10–0.18 秒；命中／穿透進入 0.03–0.06 秒。密集穿透不能每次重置全身跑步，優先用上半身 layer；若引擎第一版未提供 layer，使用短全身姿勢並從當前混合姿勢接續。只保留最新低優先碰撞演出，不排長佇列讓動作落後戰鬥。

遊戲命中由 Luau 的碰撞／技能時計決定，動畫 marker 只對齊刀光、音效與腳步，不觸發第二次傷害。root motion 初版關閉，位移與反彈由 Luau 管。視覺轉向可以短暫平滑，但傷害射線即時採真實方向。

速度 buff 改跑步播放速度並限於初始 0.75–1.5 倍，必要時再調步幅；不能改攻擊動畫時間而偷偷改遊戲傷害頻率。暫停停動畫；低動態關鏡頭震動／大幅縮放，但保留腿部移動與技能動作。

## 大量部隊與工具要求

Unone／Animator 提供同骨架多實例播放、blend、事件、換裝、插槽與合理的動畫 LOD；遊戲不自行寫第二套播放器。不可直接把一個展示器的重型 mixer 複製 100 份就宣稱效能合格。LOD 可降低遠處姿勢更新率，邏輯 tick 不变；須測 25／50／100 部隊及怪物潮的實際正常速度效能。

展示器新增三兵種選擇、技能組合、出發→旋轉→穿透→終結連播、反彈、到期／召回、0.25 倍慢播、骨架與武器插槽顯示。逐一檢查五部位換裝接縫、手握武器、腳掌方向、死亡後事件與資源釋放。

現有動作為程序示範，Mixamo 相容不等於已使用 Mixamo 動作。製作时沿用 Blender 角色、貼圖和骨架資產，先完成六個原定基本動作的實際盤面接入，再補技能專用與坐騎動作。
