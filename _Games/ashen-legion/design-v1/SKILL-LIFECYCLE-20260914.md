# 技能、效果實體與 BUFF：橫版試玩版

這次實作屬於遊戲規則，放在 `gameplay/skill-runtime.luau`，由 `tools/build-skills.mjs` 打包進正式 `main.luau`。不新增 Rust 引擎行為。介面採用正式 Unone Canvas；本次只驗證 1440×810、1280×720 橫版。

現行派兵費最後乘 0.5 並向上取整；騎兵同時穿這三件，每支 27 金幣。商店、寶箱、科技和最高階附魔池都可取得。新增「餘火巡獵」「疾走鍊金」採購方向，流派共 11 種、技能與裝備各 48 種。指定採購會讓商店首格優先供應缺少的核心裝備，沒有隱藏套裝加成。

三技能重複來源不增加獨立發射器：每多一份，技能傷害 +25%，最多 +100%。生命、速度、範圍等既有修正仍可組合。範圍技能遵守寬刃的半徑與傷害折衷；鳳凰的選敵射程和灼燒不算範圍攻擊。

## 不疊加與歸屬

- 同一隻怪物全場只有一個「中毒」及一個「灼燒」計時器，兩種狀態可並存。
- 再次沾染只刷新到期時間，不重置下一次扣血時間，不立即補一跳。較強傷害接管數值及玩家歸屬；同強度保留先施加者。在該狀態結束前，較弱來源不會覆蓋強者。
- 每兵最多四片有效毒霧；第五片落地會結束最早生成的那片。這是公開的玩法上限，避免速度堆疊無限鋪場。
- 移動依每段實際行進距離累計，包括反彈；空中與原地旋轉不計。一次步進可跨越多個門檻。接觸致死當下尚未完成的詠唱會取消。
- LOCK 限制同樣套用火環、選敵、毒霧與持續傷害。被鎖定的怪物死後，已飛出的火鳥消散，不轉移目標。AUTO 不限制正常範圍傷害。
- 已發出的火鳥、毒瓶、毒霧與中毒／灼燒可在士兵死亡或召回後繼續，保留原付款及玩家快照；不能復活原士兵。火焰斗篷與未完成施法會中止。
- 沒錢且沒士兵時，若仍有已釋出的有效傷害，會等它處理完再判斷破產；回合時限照常。回合結束立即清除所有技能效果，結算演出中不繼續傷害或發獎。

## 三條獨立生命週期

|領域|狀態|責任|
|---|---|---|
|施法|`windup → release → channel → end`|詠唱、施展瞬間、維持／收勢、結束；可由來源消失而提前 `end`。各階段時間可調，無維持型技能可跳過 `channel`。|
|技能效果實體|`spawn → flight → active → death`|毒瓶生成與飛行，落地轉成毒霧，最後消散；火鳥命中後直接進入 `death`。|
|狀態效果|`apply → active / refresh → expire`|中毒、灼燒的施加、續期、定時跳傷與消退；亦顯示既有加速、士氣集結、爆擊增益、剩餘穿透和冰緩。|

`S.skillRuntime` 輸出三組活動狀態與最多 128 條轉換事件；附來源 ID、玩家 ID、目標 ID、位置、時間、半徑與進度，可用於錯誤定位和重播。觀察資料沒有函式或循環引用。新技能的參數在 `R.definitions`，行為在 Luau 的 attach／release／update；之後增加行為仍需實作與測試，不是任意 JSON 都能自動執行。

既有被動數值與瞬間命中技能維持原觸發方式；本次不替瞬間技能強塞詠唱延遲。

## 演出

- 角色以現有伸展／攻擊動作銜接詠唱與施展，保留出生、反彈、接觸與死亡演出的優先順序；尚未另製全新的專屬施法骨架動作。
- 火焰斗篷：貼身斷續火環、酒紅焰形與短亮芯；鳳凰：琥珀色翼形、分叉尾焰與命中火花；魔藥瓶：綠色瓶體弧線、低透明度毒域及稀疏上升毒氣。
- 灼燒與中毒有附著粒子與各自色系的較小跳傷數字；強化狀態使用小型光紋。所有位置、半徑、進度來自 Luau；渲染器不選敵、不扣血。
- 細節最多 36 個事件、兩批 GPU 幾何、共享固定緩衝。毒霧有效範圍另外保留最多 400 個廉價地面標記，不因火鳥多而完全隱藏；粒子細節可降級，傷害不受影響。
- 三件新裝備都有 SVG 圖示、Blender 源檔、GLB 模組與繪本色貼圖。

## 驗證與限制

`tools/verify-skill-lifecycle.mjs` 使用正式 Unone WASM：40 項生命週期／非疊加／LOCK／反彈距離／歸屬／開獎檢查，以及三兵種各 900 步的正常更新流程，逐步核對經濟、派兵與場地範圍。

`tools/verify-skill-lifecycle-browser.cjs` 驗證正式介面的第四頁流派、指定採購、48 件模型載入，及橫版實戰、暫停、關閉 Bloom、固定渲染緩衝與壓力上限。截圖的三件裝備由瀏覽器內測試配裝提供，戰鬥、選敵、傷害、開獎都執行正式 Luau；不代表新開局免費持有裝備。影片包含介面檢查及配裝戰鬥。

參數是第一版可玩值，尚未聲稱完成 20 分鐘通關率或多人搶獎的長期平衡。正式遊戲保留原開局與隨機獲取，沒有新增測試作弊入口。
