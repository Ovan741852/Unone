# 槍兵定點投射修正

原因：`fire()` 把投射距離設成 `min(5.4, len)`，場地擴成 25 × 25 後，瞄準遠處仍會提前在 5.4 單位處落地。修正前的正式 WASM 回歸案例可重現這個限制。

修正為每次發射記住瞄準地面的 `landingX/landingZ`，飛完整段距離並在該點落地旋轉。空中保持發射時方向；滑鼠或 LOCK 目標移動不會拖走已發射部隊的落點。LOCK 的傷害目標限制及地面追蹤保留。旋轉後前進、碰撞傷害、反彈、價格與壽命規則保持；空中仍會消耗壽命。

這是 YesSir 的 Luau 遊戲規則修正，未改引擎、扇形畫面投影或碰撞場地。

驗證：

- 新增 37 項正式 WASM 案例，涵蓋近距離、中心、遠處、邊角、發射後移開滑鼠、AUTO／LOCK 目標移動、旋轉技能移植到劍兵與騎兵，以及落地後前進。
- 桌面 1440 × 900、手機橫向 844 × 390，各以真實 Canvas 滑鼠點擊測五個地面座標。點擊 → 座標轉換 → 正式模擬 → 落地旋轉，最大世界座標誤差約 0.00000102 單位，零瀏覽器錯誤。原始資料：`spear-pointer.json`。
- 50 項技能回歸與三兵種正式連射測試通過；Unone 嚴格型別檢查通過。
- 19 項 JSON 遊戲回歸全部通過，原始結果見 `current-results.json`。

重跑：`node tools/verify-spear-landing.mjs`、`node tools/verify-spear-pointer.cjs`。固定狀態案例只注入測試用的記憶體副本；實機點擊測試不修改遊戲狀態。
