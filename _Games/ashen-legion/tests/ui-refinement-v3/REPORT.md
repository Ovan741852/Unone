# 卡面、出戰路徑與元件層級調整

日期：2026-09-19。正式 Web 匯出：`http://127.0.0.1:8190/?seed=42&ui=refinement-v3`。未自動 commit／push，未改其他遊戲及引擎。

## 已實作

- 裝備卡保留名字、裝備圖、一句核心效果、售價及派兵費變化。20 批完整商品庫都檢查四種尺寸；核心效果不可被省略號吃掉。完整條件與數值仍在詳情。
- 卡片底部改成簡單的「查看詳情」提示，點整張卡進同一詳情，不再多套一個小按鈕底板。最低 44px 命中門檻照常檢查整卡，沒有降低標準。
- 六類商店保留「部隊配置」，新增「直接出戰」。直接沿用目前配置，並非自動穿上新買裝備；附魔待選、商品詳情開啟及非商店階段皆不能繞過流程。
- 新增細舊金邊、深綠皮革共用底板，替換次要按鈕、裝備槽、研究入口、AUTO 選項的過厚葉飾或簡陋底板；磚紅主操作、稀有度卡片和主視窗保留精細裝飾。
- 領地研究入口直接顯示效果／等級／成本。行囊加核心效果，中央保留兵種肖像，去掉重複的左欄小肖像，避免九宮格增加節點後超過引擎上限。
- 若裝備正由其他兵種穿戴，行囊名稱前保留持有者提示；詳情顯示穿戴者及「轉交此裝備」，沒有為了精簡而隱藏移交影響。
- 研究、札記、設定切換及配裝操作的語意名稱加上對象，不再只有難以區分的重複操作名稱。
