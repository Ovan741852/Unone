- [八張正式 PNG](../../assets/formal-ui/characters-v1/)；[無損原稿](../../art-source/hazel-characters-v1/)；[完整提示詞、來源、修訂與雜湊](../../design-v1/hazel-character-manifest.json)。

## 限制

這次是正式 UI 角色肖像替換，不包含戰場 3D 人物／怪物、歷史 HTML／DOM 原型，也沒有改玩法或另行重排介面。全頁截圖使用真實 Luau/WASM 的 fixture 狀態與正式 Canvas renderer，不是每頁自然遊玩錄影；實際操作回歸另列。尚未測 native、Safari、實體手機及完整讀屏。

素材與幾何通過不等於 UX 審核完成。資訊重複、主次層級、科技技能名稱仍顯示部分英文 ID 等問題，屬於接續的 UX／文案審核，不在本次換圖中宣稱解決。本次未 commit／push。
