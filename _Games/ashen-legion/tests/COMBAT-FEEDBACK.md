# 傷害跳字與大獎滾分 · 2026-09-12

正式遊戲：<http://127.0.0.1:8190/?build=combat-feedback-v1>。

## 表現

- 普通傷害為象牙白字、深色描邊，從命中位置浮起淡出；金幣另外顯示金色 `+實得金額`，不顯示倍率。
- 爆擊放大金紅傷害字，加上「爆擊」、短促斬光與金色火花。傷害來自 Luau 最終命中事件；破防抽獎落空仍會顯示傷害。
- BIG / MEGA / LEGENDARY WIN 以原創紙片與碎金徽章短暫炸出，160ms 後移往 HUD 上方，560ms 時就位，再滾分。連續大獎累加實得金額，獎級只升不降；一般小獎留在現場。
- 演出不攔截滑鼠／觸控。橫向停在上方中間，直向停在目標資訊下方；共用獎池收進左上章節資訊，怪物潮提示保留獨立位置。
- 實際金幣在原有獲獎邏輯立即入帳，滾分只播放收據，不重複發錢、不等動畫結束才發錢。灑地後飛回炮台的金幣效果保留。
- 使用已整合的 Unone 官方 Lottie host；沒有新增 Spine 或修改引擎。文字／獎章由官方 Canvas UI 呈現，沒有新增 HTML 遊戲控制項。

## 邊界

Luau 命中收據上限 128 筆、保留 1.8 秒。呈現層最多同時顯示 22 筆傷害（直向 14）、4 筆金幣、3 個王名；優先保留爆擊並避開重疊。跳字圖片快取上限 240；顯示傷害四捨五入，原始傷害與經濟維持原精度。

暫停會隱藏跳字與獎章，並凍結計時；減少動態效果設定取消飛移／縮放，保留顏色與數值。支援視窗大小與安全邊距變更。
