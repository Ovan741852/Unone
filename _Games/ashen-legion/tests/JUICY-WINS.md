# 大獎演出與結算時序 · 2026-09-12

正式入口：`http://127.0.0.1:8190/?build=juicy-wins-v1`。

## 交付行為

| 獎級 | 演出 | 對戰鬥的影響 |
| --- | --- | --- |
| BIG WIN | 短促震動、24 枚碎金、金色衝擊環，徽章飛到 HUD 空位滾分 | 繼續戰鬥；HUD 不震動 |
| MEGA WIN | 更強、更長的震動，40 枚碎金與和弦音效；沿用上方滾分 | 繼續戰鬥；若為擊敗大王的獎項，停戰後演出 3.3 秒再結算 |
| LEGENDARY WIN | 0–0.43 秒蓄光，0.43 秒爆發；原創王冠／橡葉 Lottie、金幣雨、暖金／冷青光與放射光束；0.85–4.35 秒滾分，4.45 秒封賞和弦，5.75–6.4 秒淡出 | 滿版演出，6.4 秒完成後才進入當輪結算；第七輪接遠征完成 |

Luau 的 `celebration` 階段控制時序，獲獎金額在命中時入帳，倖存返還在最終接觸與死亡處理後執行一次。動畫不抽獎、不加錢，不透過動畫完成 callback 改寫遊戲。演出期間不能派兵、換裝、開箱、回領地或前往下一輪；Pause／Escape 可暫停與繼續。離開分頁會暫停，返回後按繼續。戰鬥秒數不包含演出。

遊戲規則與轉場屬遊戲 Luau，王冠／震動／粒子／音效屬遊戲 presentation；使用已有官方 Lottie 與 Canvas UI，沒有新增 Rust 引擎規則或 HTML 遊戲控制項。普通浮動傷害與金錢仍維持 `+實得金額`。

震動同時偏移實際相機位置與目標，使用同一相機拾取地面；沒有 CSS 拉動畫面或累積漂移。最多 4 個短震動，兩次觸發間隔至少 120ms；终極大獎可升級覆蓋。桌面終極金幣／碎金預算 104，手機 60。開啟系統「減少動態效果」時取消震動、閃光、光束旋轉與金幣雨，保留靜態王冠、滾分與結算順序。音效遵守靜音與暫停。

結算頁原先漂浮寶箱遮到返還／結晶列，現在縮小移到開箱控制旁，直向移到按鈕下；移除重複的開箱文字。
