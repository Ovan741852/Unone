# 精細遠征地圖 · 2026-09-19

已接入正式 Web 遊戲，不是獨立美術預覽。玩法仍是七站線性遠征；沒有新增選路、改站數、改價格或改行軍時間。

## 成果

- 精細森林地圖、七處不同地標及透明金屬路標，沿用榛姨／核准森林主視覺的筆觸與綠金色系。
- 左側地圖等比顯示，右側聚合本站名稱、抵達／行軍狀態、下一站與「選擇景點」。章節台詞只留在景點页；地圖移除無關貨幣，讀屏狀態亦同步調整。
- 已行經實線、未來點線、當前站放大標記；移動徽記依曲線前進。路線與遊戲標記共用 Luau 站點座標。
- 行軍時按鈕停用、使用次要底板；仍由原有 1.5 秒行軍自動進入景點。進出地圖不重新抽景點。
- 原圖保留，無程式修圖。生成提示詞、參考、原稿及雜湊在 [manifest](../../design-v1/expedition-map-manifest.json)。建置時最後套用映射，舊圖資源別名亦改用新圖。
