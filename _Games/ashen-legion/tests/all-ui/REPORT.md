## 設計檢查與限制

Impeccable 用於重排、邊界狀態與檢查維度；Ponytail 用於延伸共用元件，未引入第二套 UI renderer 或套件。設計偵測器只掃來源，不理解 Canvas：`jhenghei` 字型別名警告對應已記錄的 Microsoft JhengHei；`loading-sweep` 是載入中的進度掃光，不是捲動內容，且已有 reduced-motion 靜態替代。實驗室與載入層的色彩提示未冒充本次正式 Canvas 的合格或不合格證據。
