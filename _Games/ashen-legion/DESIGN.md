# Design System: 森林領主

## Overview

**Creative North Star: "榛姨的森林商店"**

這是使用者已確認方向的整理，不是新提案。以榛姨的衣料、皮革與舊金配件串起精細手繪遊戲 UI；墨綠底、舊金裝飾、磚紅主要操作，保留角色感與卡片收藏感。材料有細節，內容區保持安靜，閱讀與操作不被裝飾壓過。

這套精細共用元件已擴充至正式 Web 介面。2026-09-19 再將三種兵種與五位店主肖像重繪，沿用榛姨的材質、色調和細緻筆觸；榛姨與領主使用原核准素材。戰場 3D 模型與歷史原型不在此肖像替換範圍，不能宣稱全遊戲所有素材都已重製。左商人／四卡是商店構圖，不是所有頁面的強制模板。

Key Characteristics:

- 榛姨與精細手繪素材的統一色調、線條與材質。
- 置中視窗、清楚的前後層次、安靜的內容底材。
- 共用卡片／按鈕與九宮格，角色和裝備保留原比例。
- 圖示＋數字呈現資源，詳情承接長敘述與完整技能。

製作及驗收入口：[UI-PRODUCTION.md](UI-PRODUCTION.md)。抽取來源是正式程式、現行商店規格和 2026-09-19 修正後截圖，不以早期預覽取代正式實作。

## Colors

### Primary

磚紅用在主要操作；墨綠／青綠作為主視窗與次要按鈕基底，舊金與皮革棕提供輪廓和裝飾。這些材質來自核准 PNG，不以臆測的單一 CSS 色碼取代。榛姨來源為 `assets/formal-ui/quartermaster-v1.png`，實際生效資產以 `assets.json` 的映射為準。

### Neutral

前言 token `scene-ink` 用於頁面底色（`presentation/landscape-host.css`）；`parchment-text` 是正式 Canvas 文字色（`host.mjs`）。鍵盤焦點使用 `focus-gold` 與 `focus-separator`，來源為 `presentation/shop-accessibility.mjs`。

稀有度以商品底板變體呈現，仍保留同一裝飾語彙；詳情文字提供稀有度名稱。不要只靠色差辨識狀態，不把整個頁面改成另一套冷色主題。

## Typography

正式 Canvas 與文字量測使用同一字型堆疊，見前言 `typography.body`。現況依賴 Windows 微軟正黑體與系統 fallback；跨裝置完全一致仍需有授權的字型檔，尚未完成。

固定 1920×1080 設計像素：商店正文 22px、名稱／價格 28px、操作 24px；全頁既有驗收底線仍為輔助 14px、主要 16px。`presentation/adaptive-ui.mjs` 保留相容檔名，但不再依視窗改字級或重排。

名稱單行，太長可省略但需有完整詳情；卡面保留一句核心效果，最多兩行，整體縮放時也不移除。完整數值、發動條件與限制在詳情。價格與 `12`、`30%` 等連續數值不要拆散。以實際字形量測爆框，不靠字數估算或裁切掩蓋。

## Layout

正式座標使用 100×100 正規化設計空間，再轉成畫布像素。原始節點是底部起算，UI 組裝 helper 接受頂部起算；寫新轉換時不可混用。邊距與字級需分清 units 與 CSS px。

商店主視窗四周保留背景，不滿版；左側商人、右側四卡水平排列、底部獨立操作列，點卡開完整詳情。精確數值與 `s1…s8` 間距表只在 [商店詳細規格](design-v1/UI-DESIGN-GUIDELINES-20260919.md)維護。

2026-09-19 使用者修訂：這是電腦遊戲，採唯一 **1920×1080 固定構圖**，不做行動版、窄版重排、斷點或直向旋轉。預覽視窗只將包含場景、UI、載入畫面、焦點框的完整 stage 等比縮放並置中留黑邊；輸入使用同一座標轉換。商店卡片整張可點，主要按鈕固定 6.5 units（70.2 設計像素），全頁互動驗收底線 44×44 設計像素。不能把縮放後的實際 CSS 像素和設計像素混為一談。

2026-09-20 使用者修訂：所有「返回／關閉」語意的入口統一放在目前視窗或頁面的右上角，使用共用 `icon-close` 叉叉與至少 44×44 設計像素的命中區；底部操作列只保留購買、穿戴、出戰、確認等正向操作。不可再用底部「返回商店／返回行囊／返回主選單」文字按鈕取代叉叉。不可逆的刪除、保留或取消確認仍可保留明確文字操作。

三選一景點沿用精細商人卡，三張直式卡水平並列；移除寬故事底板，章節短句留在卡列上方。讀取進度、刪檔確認與設定不顯示局內金幣／結晶；城鎮只顯示永久建材。研究圖示 72px、費用圖示 36px、建材餘額圖示 48px；名稱與效果共用左對齊軸，成本圖示與數字緊鄰、垂直置中。存檔卡採同套九宮格，主要進入／次要刪除同列，文字避開徽章與金邊。

## Elevation & Depth

以模糊／壓暗的遊戲後景、深綠實色內容底、精細框材及詳情遮罩建立層次。框材本身已有光影，不額外堆疊不一致的卡片陰影，也不把小塊紋理放大充滿內容區。

鍵盤焦點的深色分隔環是可讀性輔助，不是裝飾光暈。詳情遮罩固定在背景控制項之上、詳情內容之下；背景按鈕不能穿透操作。

## Shapes

形狀取自正式素材，不以一般網站圓角矩形代替精細框材。九宮格四角等比、邊緣只沿需要方向延展；按鈕先去除透明外邊，裝飾安全區與文字／命中區分開。

切線順序為左／上／右／下，來源像素如下；具體來源尺寸由 `presentation/ui-skin-data.mjs` 生成管理：

| 母元件 | 來源切線 | 伸縮基準 |
| --- | --- | --- |
| `shop-window-panel-v2` | 360 / 540 / 360 / 360 | 視窗邊框依設計像素等比 |
| `shop-card-*-v2` | 210 / 360 / 210 / 360 | 依卡寬保留裝飾比例 |
| `shop-button-*-v2` | 300 / 100 / 300 / 100 | 依一致按鈕高度保留四角 |
| `control-quiet-v3` | 80 / 80 / 80 / 80（去透明留白後） | 細舊金邊，依設計像素等比；共用次要操作／裝備槽／研究／AUTO 底板 |

這些是現行資產契約，不是新圖片可以直接套用的魔法數字；更換母圖需重新定切線及驗證。

地圖使用 `assets/formal-ui/map-v2/forest-map-v2.png` 與透明路標，色調／筆觸沿用榛姨與核准森林主視覺。路線是程式幾何，不烙進生成圖；站點及移動曲線共用 Luau 的 `expeditionPoints`。實線表示已行經、點線表示未抵達，本站另有放大環與文字，不只靠色差。行軍期間停用「選擇景點」，仍沿用原本 1.5 秒自動抵達流程，沒有改遊戲規則。章節台詞只留在景點畫面，地圖不顯示無關貨幣。

固定桌面地圖保留原圖比例，路標以設計像素等比配置，資訊在右側獨立欄；圖、線與標記不套用彼此錯開的進場位移。生成來源／提示詞／映射保存於 `design-v1/expedition-map-manifest.json`；舊地圖資源 ID 亦指向新圖，避免重建回退。驗證見 [地圖交付](tests/map-layout/REPORT.md)。

正式 UI 的劍兵、槍兵、騎兵、刻印師伊薇、藥師芙蘭、軍械學者瑟恩、鍛造師布洛克與林巫莫拉現使用 `assets/formal-ui/characters-v1/` 的精細透明 PNG。刻印師與軍械學者不再共用肖像。`design-v1/hazel-character-manifest.json` 保存提示詞、原始輸出、雜湊及 runtime 映射；`build-formal-ui.mjs` 最後套用此映射，舊 SVG 僅保留追溯。旧領主、商人及角色合成主視覺的舊資源名稱，也映射至已核准精細稿，避免備援路徑重新出現向量角色。

角色使用等比 contain，禁止拉伸、加實色背景或裁掉頭飾／武器。原稿與 runtime PNG 皆保留生成的真實 alpha；幾何／透明度測試與人工目視並行，不能把透明度數字當成解剖或美術自動驗收。證據見 [角色替換報告](tests/character-art/REPORT.md)。裝備店保留核准的橫向四卡構圖；其他商店的摘要可節略，但購買前必須能看到完整效果。

動畫由 `presentation/ui-motion.mjs` 統一：商品進場 220ms、按序每張錯開 20ms、cubic ease-out；hover 1.012 倍、按下 0.98 倍、放開回復 280ms。圖、字、底板與命中區同組，重要數值不延遲顯示；reduced-motion 保留可操作的靜態結果。

`.impeccable/design.json` 是歷史設計輔助資料，不是 runtime 設定；舊斷點／旋轉資料由本頁固定桌面規格取代。Canvas 九宮格元件不以簡化 HTML 假裝等效；現行成果見 [固定桌面驗收](tests/desktop-ui-v4/REPORT.md)及 [商店截圖](tests/shop-layout/components-1920.png)。

商店操作列同時提供「部隊配置」與「直接出戰」。後者沿用目前裝備並進入原本的戰鬥入口，不自動穿戴新買裝備；附魔待選、商品詳情開啟時不能繞過決策出戰。價格、戰鬥與 RNG 規則不變。

精細裝飾保留在主視窗、稀有度卡片和主要操作；小控制項不再每顆都帶厚葉飾。新底板原稿、提示詞及雜湊見 `design-v1/ui-refinement-v3-manifest.json`，本輪驗證見 [調整報告](tests/ui-refinement-v3/REPORT.md)。

## Do's and Don'ts

### Do

- 沿用已確認的榛姨美術方向和共用母元件。
- 分開記錄全局視覺語言與商店專屬構圖／玩法。
- 檢查真實像素、字形、點擊、焦點與動畫狀態，再對照核准稿。
- 用正式截圖與測試證據說明完成範圍。

### Don't

- 不把整張生成 UI 圖當成正式介面，不把可變文字烙進圖片。
- 不逐張卡片另寫高度、字級與拉伸方法，不把按鈕四角拉扁。
- 不靠縮字、裁切或降低測試門檻處理爆框。
- 不拷貝參考遊戲美術，不把未驗證頁面／平台說成已完成。
